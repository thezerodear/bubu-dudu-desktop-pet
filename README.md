# 🐼🐻 Bubu & Dudu Desktop Pet v1.0.2

แอปพลิเคชัน Desktop Pet น้องหมี Bubu & Dudu เดินเล่นบนหน้าจอ รองรับทั้ง **Windows** และ **macOS** พัฒนาด้วย **Electron**

---

## ✨ ฟีเจอร์หลัก (Features in v1.0.2)

- **ระบบอัปเดตอัตโนมัติผ่าน GitHub (GitHub Auto-Updater 🔄)**:
  - เชื่อมต่อกับ GitHub Releases API ตรวจสอบเวอร์ชันใหม่อัตโนมัติทุก 4 ชั่วโมงและตอนเริ่มแอป (ไม่รบกวนผู้ใช้)
  - มีปุ่ม **"ตรวจหาอัปเดต... (Check for Updates 🔄)"** ทั้งใน System Tray และคลิกขวาที่ตัวน้อง
  - เมื่อมีเวอร์ชันใหม่ จะมีไฮไลท์แจ้งเตือนบนถาดระบบ และบอลลูนข้อความบนหัวน้องๆ
  - รองรับการดาวน์โหลดไฟล์ตรงและสั่งเปิดติดตั้งอัตโนมัติ (รองรับทั้ง Windows `.exe` และ macOS `.zip`)
- **เครื่องมือ Asset Importer สำหรับนำเข้าไฟล์ GIF ในอนาคต 🛠️**:
  - มีคำสั่ง `npm run import:gif` สำหรับนำเข้าภาพ GIF ใหม่ พร้อมลบพื้นหลังขาวอัตโนมัติ และลงทะเบียนเข้าสู่ระบบทันทีโดยไม่ต้องแก้โค้ดมือ
- **ระบบมีชีวิตชีวา (Tamagotchi & Vitality Needs System)**:
  - **ระบบนอนหลับ 5 นาที (5-Minute Beauty Nap 💤)**:
    - เมื่อน้องๆ เหนื่อยหรือไม่มีการรบกวน น้องจะนอนหลับพักผ่อนยาวประมาณ 5 นาที พร้อมอนุภาค `💤` ลอยฟุ้ง
    - ขณะหลับ พลังงานจะฟื้นฟูเต็ม 100% ⚡ และอัตราการหิวจะลดลงครึ่งหนึ่ง
    - เมื่อครบ 5 นาที น้องจะตื่นเองอย่างสดใส พร้อมปล่อยดาวประกายวิบวับ `✨` และท่าดีใจฉลอง
    - สามารถสั่งให้น้องนอน หรือปลุกน้องได้ทันทีผ่านคลิกขวา หรือ System Tray
  - **ระบบความหิว & ให้อาหาร (Hunger & Feeding System 🍽️)**:
    - น้องๆ จะหิวตามกาลเวลา หากค่าความหิวลดลง (<35%) จะมีบอลลูนความคิดอยากกินของอร่อยลอยขึ้นมา (🍙, 🧋, 🍓, 🍰, 🍗, 🍕) และเดินช้าลงเล็กน้อย
    - หากหิวจัด (<15%) น้องจะแวะร้องไห้/งอแงขอของกิน
    - **เมนูให้อาหารหลากหลาย**: สตรอว์เบอร์รี่สด 🍓, ชานมไข่มุก 🧋, เค้กสตรอว์เบอร์รี่ 🍰, ข้าวปั้นโอนิกิริ 🍙, น่องไก่ทอดกรอบ 🍗, พิซซ่า 🍕
    - เมื่อให้อาหาร อาหารจะลอยลงมาให้กิน พร้อมเสียงเคี้ยวและหัวใจ `😋` `💖` เติมเต็มความอิ่มและเพิ่มความสุข
  - **บอลลูนความคิดลอยได้ (Thought Bubbles)**:
    - แสดงความคิด ความรู้สึก หรือง่วงนอนอย่างมีชีวิตชีวา
- **แก้ไขทิศทางการเดินและสเก็ตบอร์ด (Direction & Movement Fix)**:
  - แก้ไขปัญหาภาพสเก็ตบอร์ดและท่าย่างก้าวที่ไหลกลับทิศ ให้หันหน้าและพุ่งไปข้างหน้าอย่างถูกต้องตามทิศทางการเคลื่อนที่จริง ทั้ง Bubu และ Dudu
- **อนิเมชั่นน่ารักครบชุด**:
  - **Bubu (21 ท่า)**: เดินคลาสสิก (`walk`), เดินร่าเริง (`walk2`), เดินเด้งดึ๋ง (`walk3`), สเก็ตบอร์ด (`skateboard`), บินเฮลิคอปเตอร์ร่อนลงพื้น (`helicopter`), ชี้เมาส์ (`mousepoint`), เตะขาเล่น (`kickingfeet`), เครียดดิ้นพราด (`stressing`), ดีใจฉลอง, อ่านหนังสือ, ระแวง (Sus), ล้อเลียน, ร้องไห้, เศร้า, กรี๊ด, เครียด, นอนราบ (`sleep`), นอนนั่งกอดเข่า (`sitsleep`), **โดนหิ้วคอเคว้งคว้าง (`bubu-danggling2.gif`)**, โดนหิ้วดิ้น (`bubu-grabbed.gif`)
  - **Dudu (27 ท่า)**: เดินคลาสสิก (`walk`), เดินน่ารัก (`walk2`), เดินกระทืบเท้าโมโห (`angrywalk`), สเก็ตบอร์ด (`skateboard`), **ขี่สกู๊ตเตอร์สุดซิ่ง 🛴 (`dudu-skooter.gif`)**, ร้องเพลงพร้อมโน้ตดนตรี (`singing`), วิดพื้นออกกำลังกาย (`pushup`), กระโดดเชือก (`ropeskipping`), แอบมองหลังขอบจอ (`peeking`), ชี้เมาส์ (`mousepoint`), นั่งกระโดดดึ๋งๆ (`sit_jump`), เต้น, หัวเราะ, อ่านหนังสือ, โกรธโมโห (`mad`), ขว้างขวด (`throwing_bottle`), ห้ามแตะ (denied), แจกใบแดง, ล้อเลียน, ร้องไห้, กรี๊ด, ดิ่งพสุธาตกจากฟ้า (`falling`), นอนราบ (`sleep`), นอนนั่ง (`sitsleep`), **โดนหิ้วคอเคว้งคว้าง (`dudu-danggling2.gif`)**, โดนหิ้วดิ้น (`dudu-grabbed.gif`)

  - ปรับขนาดตัวละคร (Tiny 70%, Normal 100%, Large 130%, Huge 160%)

## 🚀 วิธีการรันใช้งานทันที (Run with npm)

ตรวจสอบว่ามี [Node.js](https://nodejs.org/) (เวอร์ชัน 18 ขึ้นไป) ติดตั้งอยู่ในเครื่อง:

```bash
# ติดตั้ง dependencies (ทำครั้งแรก)
npm install

# รันโปรแกรม Desktop Pet
npm start
```

## 📦 วิธีการ Build เป็นไฟล์ติดตั้ง / Portable (.exe และ .app / .dmg)

โปรเจกต์นี้ตั้งค่า `electron-builder` สำหรับสร้างไฟล์แจกจ่ายข้ามแพลตฟอร์ม:

### สำหรับ Windows (`.exe`):
```bash
npm run build:win
```
ไฟล์ผลลัพธ์จะอยู่ในโฟลเดอร์ `dist/`:
- **Portable (.exe)**: ดับเบิ้ลคลิกเปิดใช้งานได้ทันทีโดยไม่ต้องติดตั้ง พกพาใส่ Flash Drive ได้
- **Setup Installer (.exe)**: ตัวติดตั้งมาตรฐานสำหรับ Windows

### สำหรับ macOS (`.app` ในไฟล์ `.zip`):
```bash
npm run build:mac
```
ไฟล์ผลลัพธ์ในโฟลเดอร์ `dist/`:
- **Apple Silicon (M1/M2/M3/M4)**: `dist/Bubu & Dudu Pet-1.0.1-mac-arm64.zip`
- **Intel Mac (เช่น MacBook Pro 2020 Core i5/i7)**: `dist/Bubu & Dudu Pet-1.0.1-mac-x64.zip`

> **วิธีเปิดใช้งานบน macOS Sonoma 14+ (รวมถึง MacBook Pro 2020)**:
> 1. แตกไฟล์ `.zip` จะได้แอป `Bubu & Dudu Pet.app` (สามารถลากไปไว้ที่ `/Applications` ได้เลย)
> 2. เนื่องจากแอปไม่ได้ซื้อใบรับรอง Apple Developer ID (\$99/ปี) macOS Sonoma จะบล็อกไว้เป็นค่าเริ่มต้น (อาจขึ้นว่า "แอปเสียหาย / Damaged" หรือ "ไม่สามารถเปิดได้")
> 3. **ปลดบล็อกง่ายๆ (ทำเพียงครั้งแรกครั้งเดียว)**:
>    - เปิด **Terminal** (กด Cmd + Space พิมพ์ Terminal)
>    - พิมพ์คำสั่ง: `xattr -cr "/Applications/Bubu & Dudu Pet.app"`
>      *(หรือพิมพ์ `xattr -cr ` แล้วลากแอป `Bubu & Dudu Pet.app` มาวางใน Terminal แล้วกด Enter)*
>    - หรือไปที่ **System Settings** > **Privacy & Security** > เลื่อนลงมาที่หัวข้อ Security จะมีปุ่ม **"Open Anyway"** ให้กดอนุญาต

## ⌨️ ปุ่มลัด (Shortcuts)

| ปุ่มลัด | การทำงาน |
| :--- | :--- |
| `Ctrl + Shift + G` (Win) / `Cmd + Shift + G` (Mac) | สลับโหมด **Ghost Mode** (คลิกทะลุตัวละคร / ใช้งานเมาส์ตามปกติ) |
| คลิกซ้ายที่ตัวละคร | สะกิด / เปลี่ยนท่าทาง |
| คลิกลากที่ตัวละคร | ย้ายตำแหน่งไปทั่วหน้าจอ |
| คลิกขวาที่ตัวละคร | เปิดเมนูเลือกท่าทางและตั้งค่า |

## 📁 โครงสร้างโปรเจกต์

```
├── package.json          # กำหนดคำสั่งรันและคอนฟิก electron-builder
├── tray-icon.png         # ไอคอนขนาดเล็กสำหรับ System Tray / Menu Bar
├── app-icon.png / .ico   # ไอคอนแอปพลิเคชันสำหรับ Build
├── src/
│   ├── main.js           # Electron Main Process จัดการหน้าต่างโปร่งใสและ Tray
│   ├── preload.js        # IPC Bridge เชื่อมต่ออย่างปลอดภัย
│   ├── pet.html          # หน้าต่างโปร่งใสสำหรับแสดงตัวละคร
│   ├── pet.js            # ระบบ AI เคลื่อนที่ ฟิสิกส์ และการคลิกสะกิด
│   └── styles.css        # จัดการการแสดงผล GIF, การ Flip ซ้ายขวา, และ Emote
└── *.gif                 # ไฟล์ภาพเคลื่อนไหว Bubu และ Dudu ทั้งหมด
```
